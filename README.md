# Transcribator AUD

Скелет проекта для приложения, транскрибирующего аудио в текст. Репозиторий
пока содержит только базовую инфраструктуру, необходимую для дальнейшей
разработки.

## Структура

- `app/main.py` – точка входа FastAPI-приложения с заглушкой эндпоинта
  `/transcribe` и проверкой здоровья `/health`.
- `src/transcribatoraud/` – доменные сущности и сервис для работы с моделью
  Whisper.
- `tests/` – автоматические тесты для инфраструктурных компонентов.
- `pyproject.toml` – конфигурация Python-пакета и зависимостей.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресу
`http://127.0.0.1:8000`. Для тестирования API можно воспользоваться Swagger UI
по адресу `/docs`.

## Как подготовить pull request в песочнице

В среде Code Assist PR создаётся специальной командой `make_pr`. Чтобы она
сработала, необходимо предварительно зафиксировать изменения в git:

1. Внести правки в код.
2. Убедиться, что тесты проходят (`pytest`).
3. Создать коммит: `git add . && git commit -m "Ваше сообщение"`.
4. Вызвать `make_pr` и передать заголовок и описание PR.

Если попытаться запустить `make_pr` до коммита, инструмент сообщит об ошибке и
PR не будет создан — именно это сообщение «Failed to create PR» видно на
скриншоте. Поэтому перед созданием PR всегда сохраняйте изменения в коммите.
